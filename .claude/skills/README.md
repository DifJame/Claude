# Claude project skills

These skills are project-level Claude Code skills for the `DifJame/Claude` repository.

They are available when Claude Code is opened in this repo and the current branch contains the `.claude/skills/` directory.

## Installed skills

- `/premium-design-review` — premium UI / UX review for Moscow City landing pages and service pages.
- `/luxury-copywriting` — Russian premium copywriting for real estate, service pages, Telegram posts, and commercial offers.
- `/bitrix-code-review` — Bitrix/PHP code review with focus on production safety, lead forms, encoding, and regressions.
- `/seo-landing-audit` — SEO and indexation review for Moscow-city.online service pages.

## How to use

In Claude Code, run one of these commands:

```text
/premium-design-review
/luxury-copywriting
/bitrix-code-review
/seo-landing-audit
```

You can also ask in plain language, for example:

```text
Проверь эту страницу через premium-design-review.
Перепиши этот блок через luxury-copywriting.
Перед коммитом сделай bitrix-code-review.
Сделай seo-landing-audit страницы рекламы.
```

## Important note

These skills are safe project instructions. They do not contain external scripts, dependencies, or third-party code.

Universal account-level skills for Claude Web must still be uploaded manually through Claude UI: `Customize → Skills`.
