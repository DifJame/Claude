# SEO Landing Audit

Use this skill to review service pages and landing pages for SEO and indexation readiness.

## Default context

Moscow-city.online is becoming a service portal for Moscow City.

Main service categories:

- advertising on media facades and digital screens
- daily apartment rentals
- excursions
- renovation
- apartment management
- events and venues
- coworking and mini-offices
- restaurant bookings
- news, video, FAQ

The goal is qualified applications and calls.

## Critical rule: preserve current indexation

Do not break current indexation on the existing Moscow-city.online site.

The current site already has public pages and real estate objects. These pages must not be removed, blocked, redirected, noindexed, or made unavailable unless the user explicitly confirms the change.

When reviewing or planning changes, protect:

- existing public URLs
- real estate object pages that are still needed while the separate real estate site is in development
- service pages that can attract search traffic
- sitemap generation
- robots.txt rules
- canonical URLs
- title and meta description
- single H1 per page
- public images, CSS, and JS required for rendering
- correct HTTP status codes
- internal links between services, objects, news, FAQ, and related pages

Any SEO-sensitive change must be flagged before implementation.

## Audit checklist

Check:

1. One clear search intent per page
2. Unique title
3. Unique meta description
4. One strong H1
5. Logical H2 / H3 structure
6. Useful first screen text
7. Enough commercial detail for the service
8. Local relevance: Moscow City, towers, surfaces, formats, terms
9. FAQ block for objections and long-tail queries
10. Internal links to related services
11. CTA block above and below the fold
12. Image alt text where relevant
13. Canonical and duplicate risks
14. Indexation blockers
15. Sitemap / robots readiness
16. Mobile readability
17. Page speed basics
18. Schema markup opportunities when useful
19. Redirect risks
20. Status code risks
21. Existing indexed page preservation

## Output format

Respond in Russian unless the user asks otherwise.

Use this format:

1. `Главная SEO-проблема`
2. `Что может сломать текущую индексацию`
3. `Что мешает индексации новых страниц`
4. `Что мешает заявкам`
5. `Структура страницы`
6. `Title / Description / H1`
7. `Какие блоки добавить`
8. `Внутренние ссылки`
9. `Быстрые правки на 1 день`
10. `Что проверить в Яндекс Вебмастере и Google Search Console`

## Writing rules

Do not write generic SEO advice. Tie each recommendation to the page, service, and Moscow City context.

Do not recommend keyword stuffing. Use natural premium business language.

Never recommend deleting indexed pages, blocking crawler access, or changing public URLs unless there is a clear redirect and the user explicitly approved it.
