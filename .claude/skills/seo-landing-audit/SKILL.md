# SEO Landing Audit

Use this skill to review service pages and landing pages for SEO and indexation readiness.

## Default context

Moscow-city.online is becoming a service portal for Moscow City.

Main service categories:

- advertising on media facades and digital screens
- daily apartment rentals
- excursions
- renovation
- apartment management
- events and venues
- coworking and mini-offices
- restaurant bookings
- news, video, FAQ

The goal is qualified applications and calls.

## Audit checklist

Check:

1. One clear search intent per page
2. Unique title
3. Unique meta description
4. One strong H1
5. Logical H2 / H3 structure
6. Useful first screen text
7. Enough commercial detail for the service
8. Local relevance: Moscow City, towers, surfaces, formats, terms
9. FAQ block for objections and long-tail queries
10. Internal links to related services
11. CTA block above and below the fold
12. Image alt text where relevant
13. Canonical and duplicate risks
14. Indexation blockers
15. Sitemap / robots readiness
16. Mobile readability
17. Page speed basics
18. Schema markup opportunities when useful

## Output format

Respond in Russian unless the user asks otherwise.

Use this format:

1. `Главная SEO-проблема`
2. `Что мешает индексации`
3. `Что мешает заявкам`
4. `Структура страницы`
5. `Title / Description / H1`
6. `Какие блоки добавить`
7. `Внутренние ссылки`
8. `Быстрые правки на 1 день`
9. `Что проверить в Яндекс Вебмастере и Google Search Console`

## Writing rules

Do not write generic SEO advice. Tie each recommendation to the page, service, and Moscow City context.

Do not recommend keyword stuffing. Use natural premium business language.
