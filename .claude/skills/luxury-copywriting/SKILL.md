# Luxury Copywriting

Use this skill to create or improve Russian text for premium business real estate and Moscow City service offers.

## Tone

Write in Russian unless the user asks otherwise.

The text should be:

- premium but simple
- clear and business-like
- calm, confident, and practical
- focused on value, trust, and next action
- suitable for Moscow City services and real estate

Avoid:

- empty luxury cliches
- too many adjectives
- long corporate phrases
- generic slogans
- aggressive sales tone

## Principles

1. Start with the client result.
2. Explain the value quickly.
3. Use concrete benefits instead of abstract wording.
4. Make the CTA simple and natural.
5. Prefer short paragraphs.
6. Use facts, numbers, locations, formats, and process when available.

## Landing page structure

For a service page, use:

1. Hero headline
2. Short subheadline
3. 3-5 key benefits
4. Who the service is for
5. How it works
6. Trust block
7. FAQ / objections
8. CTA block

## Telegram / vertical post structure

For a real estate or service post, use:

1. Short headline
2. One hook
3. 3 key facts
4. Commercial logic
5. CTA
6. Optional story slide structure

## Output format

When creating copy, provide:

- `Основной вариант`
- `Более премиальный вариант`
- `Короткий вариант`
- `CTA варианты`

When editing existing text, provide:

- what is weak
- rewritten version
- why it is stronger
