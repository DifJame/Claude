# Top Agency — дизайн-система «Obsidian» (финальные токены)

Единый источник: **`assets/tokens.css`** (CSS-переменные) и **`tokens.json`**
(машиночитаемо, для Figma/сборки). Подключать `tokens.css` **первым**, до
`app.css`. Меняем дизайн в токенах — меняется весь сайт.

```html
<link rel="stylesheet" href="assets/tokens.css">
<link rel="stylesheet" href="assets/app.css">
```

### Правило акцента — 90 / 8 / 2
90% площади — фон и поверхности, 8% — текст и линии, **2% — accent**.
Один акцентный элемент на экран (одна кнопка / одна цифра / одна линия).
Никаких цветных свечений, неона и градиентов «от бренда» поверх фото.

## 2. Типографика

Один гротеск — **Inter** (`--font`). Вес создаётся размером и воздухом, не
жирностью. Капс — только в `caption`/eyebrow с разрядкой. Заголовки — НЕ
uppercase. Цифры (цены, ставки, площади) — табличные (`tabular-nums`).

| Роль | Токен размера | Вес | Трекинг | Интерлиньяж | Применение |
|---|---|---|---|---|---|
| Display | `--fs-display` `clamp(44–116px)` | 300 | −.035em | .95 | Hero |
| H1 | `--fs-h1` `clamp(40–96px)` | 300 | −.03em | .95 | Крупные заголовки |
| H2 | `--fs-h2` `clamp(28–52px)` | 300 | −.02em | 1.02 | Заголовки секций |
| H3 | `--fs-h3` `clamp(22–30px)` | 400 | −.02em | 1.1 | Карточки, строки |
| Lead | `--fs-lead` `clamp(16–20px)` | 400 | 0 | 1.6 | Лид / подзаголовок |
| Body | `--fs-body` `16px` | 400 | 0 | 1.74 | Основной текст |
| Small | `--fs-sm` `14px` | 400 | 0 | 1.5 | Мета, мелкий текст |
| Caption | `--fs-caption` `11.5px` | 500 | .2em ↑ | 1.2 | Eyebrow, лейблы (uppercase) |

Веса: `--fw-light 300` · `--fw-regular 400` · `--fw-medium 500` · `--fw-semibold 600`.
Длина строки текста — 60–75 знаков (`max-width` в ch).

| Параметр | Токен | Значение |

## 4. Движение

| Токен | Значение |
|---|---|
| `--ease` | `cubic-bezier(.22, 1, .36, 1)` |
| `--dur-fast` / `--dur` / `--dur-slow` | .3s / .4s / .8s |

«Замедленное время»: 300–800 мс, плавное затухание, без bounce. Появление
секций — fade + translateY(24px) со стаггером. Запрещено: glow, цветные тени,
kenburns-зум, автоплей, быстрые (<200 мс) переходы.

---

## 5. Фото и поверхности

- `--photo-filter` приглушает открыточные кадры под тёмную тему
  (Obsidian: `grayscale(.12) saturate(.8) brightness(.84) contrast(1.03)`).
- Карточки объектов — фото 4:5, **без оверлеев-бейджей**; статус — текстом.
- Тени — только нейтральные мягкие, для подъёма; без accent-свечения.
- Границы — hairline 1px на `--line` / `--line-2` / `--line-3`.

---

## 6. Hero — два варианта (A/B в прототипе)

- **A · Photo-led** — кинематографичный кадр под вуалью, для эмоции места.
- **B · Type-led** — без фото: глубокий графит, «чертёжная» сетка, крупная
  типографика-заявление и инлайн-индекс направлений. Институциональнее, тише.

Переключается в прототипе (нижний левый угол), сохраняется в `localStorage`
(`mco-hero`). Тема — `localStorage` `mco-theme`.
