# Реклама в Москва-Сити — обновление страницы `/reklama-v-moskva-siti/`

Премиальная посадочная страница услуги рекламы в Москва-Сити (медиафасады, digital-экраны,
indoor, промо, комплексные кампании). Светлая city-tech страница с синими акцентами
(hero — тёмный), **без золота**. Обновляем
существующую страницу — URL и SEO-база сохраняются.

## Файлы

| Файл | Назначение |
|------|------------|
| `template.php` | Прод-контент страницы для Битрикс (вставлять между `header.php` и `footer.php`). SEO-шапка + 10 блоков + `<picture>`/WebP. |
| `assets/ads-city.css` | Изолированные стили (`.ads-city`, классы `ads-city-*`, переменные `--ac-*`). |
| `assets/ads-city.js` | Прогрессивное улучшение: формат → форма, плавный скролл, AJAX-отправка, FAQ-аккордеон. |
| `ads-lead.php` | Обработчик заявок → лид в CRM с меткой `[Реклама в Москва-Сити]` (fallback — письмо). |
| `prototype.html` | Standalone-превью для скриншотов (плейсхолдер-фото, без Битрикса). **В прод не идёт.** |
| `assets/img/` | Плейсхолдеры (реальные фото Сити). В проде заменить и положить в `/upload/ads-city/`. |

## Установка

1. **Файлы:** `assets/ads-city.css`, `assets/ads-city.js`, `ads-lead.php` → в `/local/ads-city/`.
   Фото (hero + 6 поверхностей) в `/upload/ads-city/` — добавить `.webp` рядом с `.jpg` (см. ниже).
2. **Контент:** содержимое `template.php` вставить в тело страницы `/reklama-v-moskva-siti/`
   (не трогая шаблон, шапку, подвал).
3. **Формы:** `action` уже указывает на `/local/ads-city/ads-lead.php`. Если на сайте есть
   своя система заявок — поменяйте `action` на существующий endpoint и сопоставьте `name`
   полей с кодами текущей формы; скрытое поле `service="[Реклама в Москва-Сити]"` оставить.

## SEO (не ухудшать!)

- Перед заменой **сверьте текущие** `title`/`description`/`H1` в админке и сохраните ключевые запросы.
- `H1` — **ровно один** (в hero). Если шаблон печатает `<h1>` из `SetTitle()` — отключите его на этой странице.
- `canonical` → `https://moscow-city.online/reklama-v-moskva-siti/` (задаётся в `template.php`).
- Ключевые запросы сохранены: *реклама в Москва-Сити, реклама на медиафасадах Москва-Сити,
  digital-экраны Москва-Сити, indoor-реклама Москва-Сити, реклама для бизнеса, для премиальных брендов*.
- FAQ размечен **Microdata FAQPage**. Альтернатива — JSON-LD (тогда уберите `itemscope/itemprop`,
  чтобы не дублировать).

## Производительность (WebP)

`template.php` использует `<picture><source ...webp><img ...jpg></picture>`. Сгенерируйте `.webp`
рядом с каждым `.jpg` в `/upload/ads-city/` (например `cwebp -q 82 hero.jpg -o hero.webp`).
Hero — `fetchpriority="high"`; остальные фото — `loading="lazy"`; у всех `width/height` → CLS≈0.

## Чеклист после внедрения

200 OK по старому URL · нет `noindex`/redirect/robots-disallow · `canonical` на себя ·
один `<h1>` · `title`/`description` заполнены · у `<img>` есть `alt` · страница в `sitemap.xml` ·
форма отправляет заявку с меткой и форматом · Lighthouse mobile (LCP/CLS) не просел ·
проверка на 375px и в `prefers-reduced-motion`.
